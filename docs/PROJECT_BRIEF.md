# Project Brief

Godot 4 vertical slice inspired by the original *Metal Gear Solid*: a 5–10 minute, top-down/isometric 3D stealth mission with fixed camera zones, contextual first-person aiming, guns, inventory menus, rations, patrolling guards, cone-based sight, hearing, alerts, radar, death/checkpoint restart, and one objective/extraction loop.

Start with primitive geometry and placeholder assets. Keep gameplay independent from visuals so externally generated 3D models can be swapped in later. Distributed content must be original or properly licensed.
